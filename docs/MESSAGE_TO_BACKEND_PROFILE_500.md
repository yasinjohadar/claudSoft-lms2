# رسالة للباك إند — إصلاح خطأ 500 على بروفايل الطالب

## ملخص في جملة واحدة

**الطلب `GET /api/student/profile` مع هيدر `Authorization: Bearer <token>` يرجع 500. المطلوب إصلاح المسار ليعيد 200 مع جسم الاستجابة الموثّق في `docs/API_STUDENT_PROFILE.md`، ومراجعة الـ logs لمعرفة سبب الـ 500 (استثناء أو خطأ في قاعدة البيانات).**

---

## التفاصيل

### الطلب الذي يعيد 500

- **Method:** `GET`
- **Path:** `/api/student/profile`
- **الهيدر المطلوب:** `Authorization: Bearer <token>` (توكن طالب صالح)
- **النتيجة الحالية:** استجابة **500 Server Error**

### المطلوب إصلاحه

- أن يعيد المسار **استجابة 200** مع الجسم الموثّق (بروفايل الطالب الكامل).
- إن كان المسار غير منفّذ بعد، تنفيذه حسب توثيق البروفايل.
- إن كان منفّذًا، فسبب 500 غالباً من الخادم: استثناء غير معالج، خطأ في قاعدة البيانات، أو بيانات ناقصة.

### ما يساعد في التشخيص

1. **تفعيل سجلات الأخطاء (logs)** على السيرفر عند استدعاء `GET /api/student/profile` لمعرفة الـ stack trace أو رسالة الخطأ الداخلية.
2. **التأكد من المصادقة:** أن الـ token صحيح ودور المستخدم **طالب** (`role:student`).
3. **التأكد من تجهيز البيانات:** أن كل الحقول المطلوبة في `data` (وخصوصاً `user`, `stats`, `enrollments_summary`) تُجهَّز دون استثناء — مثلاً علاقة غير محمّلة، أو حقل `null` يُستخدم دون تحقق، أو جدول (مثل `gamification_levels` أو `user_stats`) غير موجود.

### التوثيق المطلوب

- **ملف التوثيق:** `docs/API_STUDENT_PROFILE.md`  
  يحدد شكل الاستجابة والحقول المطلوبة بالكامل لمبرمج Flutter.

```json
{
  "success": true,
  "data": {
    "user": { "id", "name", "name_ar", "email", "avatar", ... },
    "stats": { "total_points", "current_level", "level_name", ... },
    "enrollments_summary": { "total", "active", "completed" },
    "badges": [ ... ],
    "achievements_completed": [ ... ],
    "achievements_in_progress": [ ... ]
  }
}
```

للتفاصيل الكاملة لكل حقل، راجع **`docs/API_STUDENT_PROFILE.md`**.
